## What you receive

`GET /v1/forms/{id}` and every "next question" projects blocks through `toPublicBlock`. For the example above:

### What gets stored

The value is normalised before it is saved, so what you read back is not always what you sent.

| You send | Stored | |
| --- | --- | --- |
| `{"row_speed001":"col_good0001","row_price001":"col_bad00001"}` | `{"row_speed001":"col_good0001","row_price001":"col_bad00001"}` |  |

## Errors

| Code | When | Message |
| --- | --- | --- |
| `required` | an empty answer on a required block | This question needs an answer. |
| `type` | `["col_good0001"]` | Please answer each row. |
| `invalid_row` | `{"row_nope":"col_good0001"}` | Unknown row. |
| `invalid_column` | `{"row_speed001":"col_nope","row_price001":"col_bad00001"}` | Unknown column selection. |
| `incomplete_matrix` | `{"row_speed001":"col_good0001"}` — every row, when the block is required | Please answer every row. |
