### What gets stored

The value is normalised before it is saved, so what you read back is not always what you sent.

| You send | Stored | |
| --- | --- | --- |
| `"opt_founder1"` | `"opt_founder1"` |  |
| `"Founder"` | `"opt_founder1"` | a label resolves to its id |
