## Authentication

```bash
curl https://api.chatform.in/v1/me -H "x-api-key: sk_live_…"
```

[Authentication →](/docs/authentication)

## The surfaces

- **`/v1`** — the developer API. API key auth. This is what you build against.
- **`/p`** — the respondent surface the hosted form uses. Authenticated by a
  session-scoped respondent token, not by a key. Documented because a custom
  front end can talk to it directly with a token your server minted.
- **`/api`** — the dashboard's own surface. Session auth. Listed for
  completeness; it is not a stable contract for anything outside the dashboard.

## Trying a request

The reference has a request panel. Use a **`pk_test_`** key in it — anything you
type into a page is visible to that page, and a secret key sent from a browser is
refused anyway.

## The spec itself

curl https://api.chatform.in/openapi.json
